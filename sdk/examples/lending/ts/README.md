# Lending gRPC client (TypeScript)

This example shows how to call the `lending.v1.LendingService` from TypeScript.
The repository ships Node-oriented stubs generated by
[`ts-proto`](https://github.com/stephenh/ts-proto) (`buf.gen.yaml`,
`outputServices=grpc-js`) under
[`clients/ts/lending/v1`](../../../../clients/ts/lending/v1). The stubs target
`@grpc/grpc-js`, so they are used from Node.js.

## Prerequisites

- Node.js
- `@grpc/grpc-js` and `@bufbuild/protobuf`, which the generated code imports
  (both are listed in the repository root `package.json`).
- A running lending service. Its default listen address is `:50053`
  (`services/lendingd/config/config.go`); use whatever address you configured.

## Read calls

```ts
import { credentials } from "@grpc/grpc-js";
// Adjust the relative path to where this file lives in your checkout.
import { LendingServiceClient, ListMarketsRequest } from "../../../../clients/ts/lending/v1/lending";

const client = new LendingServiceClient(
  "localhost:50053",
  credentials.createInsecure(), // plaintext; use credentials.createSsl(...) for a TLS listener
);

const request: ListMarketsRequest = {};
client.listMarkets(request, (err, response) => {
  if (err) {
    console.error("listMarkets failed", err);
    return;
  }
  console.log("markets", response?.markets);
});
```

`createInsecure()` only works if the service is configured for plaintext
(`tls.allow_insecure: true` in its YAML config). `lendingd` refuses plaintext
unless its listen address is a loopback address or `NHB_ENV` is `dev`
(`services/lendingd/main.go`).

## Mutations

`SupplyAsset`, `WithdrawAsset`, `BorrowAsset`, `RepayAsset`, `DepositCollateral`,
`WithdrawCollateral` and `Liquidate` do not sign anything for you. Each request
must carry `signedTxJson`, a transaction you built and signed yourself, in the
JSON shape the node's `nhb_sendTransaction` accepts. The service relays it to the
node unchanged and returns the transaction hash; a request without
`signedTxJson` fails with `InvalidArgument: signed transaction required`
(`services/lending/server/server.go`). The Go example
[`../go/main.go`](../go/main.go) shows how to build and sign these transactions
with `sdk/lending`.

## Authentication

The service authenticates the mutation RPCs (not the read RPCs) with an API token
or an mTLS client certificate when one is configured
(`services/lending/server/auth.go`). A token is read from the `authorization`
metadata (`Bearer <token>`) or the `x-api-token` metadata. With `@grpc/grpc-js`
attach metadata like this:

```ts
import { Metadata } from "@grpc/grpc-js";

const metadata = new Metadata();
metadata.add("authorization", "Bearer <token>");
client.supplyAsset(
  { account: "nhb1...", market: { symbol: "default" }, amount: "1000", signedTxJson },
  metadata,
  (err, response) => {
    /* response?.txHash */
  },
);
```

If a proxy sits in front of the service it must forward those headers, or the
call fails with `UNAUTHENTICATED`.

## Browsers

`@grpc/grpc-js` runs in Node.js only. This repository contains no grpc-web proxy
or browser client; to call the service from a browser you would need to provide
one yourself. The protobuf schema is `proto/lending/v1/lending.proto`.
